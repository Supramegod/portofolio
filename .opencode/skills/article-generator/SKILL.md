# Article Generator

Structure every draft as:

1. **Title** (H1) — includes primary keyword, ≤60 chars.
2. **Meta description** — ≤160 chars, includes keyword and CTA.
3. **Introduction** — hook + what the reader will learn.
4. **2-5 H2 sections**, each covering one subtopic. Where relevant add H3 sub-sections.
5. **Conclusion** — summary + CTA.
6. **FAQ** (optional) — 3-5 Q&A pairs if the topic supports it.

Keyword placement rules:
- Keyword in title (once, naturally)
- Keyword in H2 (at least one)
- Keyword in first 100 words
- Keyword density 0.5-2.5%

Write in the user's target language. Default: Indonesian unless specified.
