# AIDA Copy Structure

Given a product/service/target audience, generate copy following AIDA:

1. **Attention** — Headline (≤30 chars) that stops the scroll. Use hook techniques.
2. **Interest** — 2-3 sentences that explain the unique value. Keep benefits front.
3. **Desire** — Social proof, results, testimonials, or time-saving statistics.
4. **Action** — Clear CTA with urgency or scarcity ("Shop Now — 50% Off Today").

Output structure:
```
Headline: [Attention grabber]
Body: [Interest + Desire paragraphs]
CTA: [Action button text]
```

Also suggest 2 A/B test variants with different hooks.
