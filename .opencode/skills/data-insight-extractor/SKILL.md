# Data Insight Extractor

Given analytics data (numbers, screenshots, or descriptions):

1. **Traffic trend** — month-over-month or year-over-year change. Up/down/flat?
2. **Bounce rate analysis** — is it above 60%? Which pages have the highest?
3. **Top landing pages** — which pages drive the most traffic? Are they optimized?
4. **Drop-off points** — where in the funnel do users leave most?
5. **Device breakdown** — mobile vs desktop vs tablet performance.
6. **Geographic patterns** — where do the best-converting users come from?

Output: 3-5 key insights phrased in plain language + recommended actions per insight.
